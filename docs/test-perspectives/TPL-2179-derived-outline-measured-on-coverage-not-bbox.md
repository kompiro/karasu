# TPL-2179: 広げた図形は実被覆で測る

## 観点

枠を「本来の範囲の外にある要素まで届かせる」ために広げると、図形は矩形でなくなる。
このとき **bounding box は図形ではない** — 実際には覆っていない行を含む。逆に、
記録上の矩形（タイトルの基準として本体のまま据え置くことがある）は広げた分を
含まない。**含む/含まないを判定するコードとテストは、必ず実被覆（覆っている矩形の
集合）を見る**。bbox で測れば過剰に、記録矩形で測れば過少に判定する。

karasu の boundary 多重包含（#2179）では次の 3 つが同時に成り立っている:

| 何を | どの表現で |
| --- | --- |
| フレームのタイトル位置・drawio export・collapse control | 記録矩形（帯の本体） |
| 描画の輪郭・ルーティングの障害物・偽の包含チェック | `coverage`（本体 + 各 strip） |
| bbox | **どこでも使わない** |

### 広げる述語は「非メンバーを飲み込まないこと」で決める

「隣の帯だから届く」のような**位置関係だけの述語**は、あいだにある行を無視する。
#2179 のプロトタイプ実測では、帯の隣接で決めた reach が
**非メンバー 1 枚を 100%、別のモデルで 23% 覆った** — どちらも普通に書かれるモデルで。
配置側の改善（共有ノードを継ぎ目に寄せる #2176）は問題を狭めるが消せない
（帯内の依存が動かすことを拒むノードがあり、3 つの boundary が共有するノードは
高々 1 つの方向にしか寄せられない）。したがって述語は
**「届く先までの回廊に非メンバーのカードが 1 枚も無いこと」**で書き、
満たさないときは広げずに縮退表示へ落とす。

**偽の包含を作らないことが、包含を見せることより優先する。** 枠が非メンバーを
囲んでいる図は、単に情報が足りない図より悪い（読み手が誤った所属を読み取る）。

### 一括移動は派生ジオメトリも連れて行く

`coverage` のような派生ジオメトリは記録矩形とは別のオブジェクトなので、
座標正規化のような**一括シフトのループが記録矩形しか触らないと、広げた分だけが
取り残される**。#2179 の実装中に実際に起きた: 正規化の +24px が本体だけに適用され、
輪郭は 24px ずれた場所に描かれ、ルーティングは誤った行を覆われていると見なし、
偽包含チェックはカードと噛み合わない枠を測っていた。症状は「図がわずかにずれる」
ではなく「判定が全部静かに間違う」である。

## 想定される失敗モード

- 包含判定を **bbox** で書き、L 字の枠が実際には覆っていない行のカードを「含む」と
  判定する（ルーティングが空白を避けて遠回りする／偽包含チェックが誤検出する）。
- 包含判定を**記録矩形**で書き、広げた部分を一切見ない。テストは緑のまま、
  実際の描画では非メンバーを覆っている（**チェックが no-op に退行しても気づけない**）。
- 広げる述語を**位置関係**（隣接・距離・同じ列）で書き、あいだの要素を無視する。
- 一括シフト / オフセット / 正規化のループが**派生ジオメトリを更新し忘れる**。
- 「高々 1 つしか一致しない」を前提にした早期 `break` が残り、重なりが成立した後も
  最初に見つかった 1 つしか返さない（#2179 の `buildFrameOfNode`）。

## チェックリスト

図形を既定の範囲外へ広げる実装・変更で、以下を確認する:

- [ ] 実被覆（覆っている矩形の集合）が**データとして持たれており**、輪郭描画・
      障害物判定・包含テストがすべてそれを読む。bbox はどこでも使っていない。
- [ ] 広げる述語が**「覆う先までに非メンバーが無いこと」**で書かれている
      （位置関係だけの述語になっていない）。満たさないときの縮退表示がある。
- [ ] **非メンバーを覆っていないこと**を、実被覆に対して全ペアで測る絶対テストがある
      （サンプルではなく集合。karasu では
      `packages/core/src/renderer/boundary-frame-containment.test.ts`）。
- [ ] そのテストに**検出器自身の柵**がある — 意図的に非メンバーへ被せたケースで
      指摘が出ることを assert する。**記録矩形を伸ばす経路と実被覆を足す経路の
      両方**を試す（片方だけだと、もう片方の読み取りが no-op に退行しても緑のまま）。
- [ ] 座標を一括で動かすパス（正規化・オフセット・スクロール補正）が**派生ジオメトリも
      動かす**。
- [ ] 「1 つしか一致しない」前提の早期 `break` / 単数の戻り値が集合に一般化されている。
- [ ] ルーティングの再計測を行った（[TPL-1927](TPL-1927-routing-measures-crossings-and-penetrations.md)）—
      広げた分は新しい障害物ジオメトリであり、貫通・共線オーバーラップの数値は
      前回の計測から持ち越せない。
