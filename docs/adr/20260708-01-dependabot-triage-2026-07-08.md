# ADR-20260708-01: Dependabot Triage (2026-07-08) — `actions/cache` 6.1.0

- **日付**: 2026-07-08（水曜）
- **ステータス**: 決定済み
- **関連**:
  - PR [#1853](https://github.com/kompiro/karasu/pull/1853) — `chore(deps): bump actions/cache from 5.0.5 to 6.1.0`
  - [ADR-20260329-01](./20260329-01-dependabot.md) — Dependabot 採用
  - [ADR-20260630-03](./20260630-03-dependabot-triage-2026-06-30.md) — 前回の triage（`actions/checkout` 7.0.0）

## 背景

2026-07-08 時点で開いていた Dependabot version update PR 1 本を triage した。サプライチェーン攻撃のリスクを踏まえ、bump 種別を問わず upstream まで遡ってリスク分析した。

| PR | 対象 | bump | 変更概要 | CI |
|----|------|------|----------|----|
| [#1853](https://github.com/kompiro/karasu/pull/1853) | `actions/cache` 5.0.5 → 6.1.0 | major | v6.0.0 での ESM 化 + 内部依存 bump（`@actions/cache`^6 / `@actions/core`^3 等）、v6.1.0 で read-only token 時のキャッシュ書き込みエラー処理を追加 | 全 check green |

### リスク分析の結論

- **リリースノート / CHANGELOG**: major 化の主因は **v6.0.0 の ESM 移行**（action 本体のバンドルを ESM 化し、`@actions/cache` を ^6.0.1、`@actions/core` を ^3.0.1 等へ bump、テスト基盤を Jest v30 へ更新）。v6.1.0 は `@actions/cache` を v6.1.0 に上げ、**read-only token でのキャッシュ書き込みエラーを扱う**（save-only の冗長な "Cache save failed" 警告を debug ログに降格）。利用側 API（`key` / `path` / `restore-keys`）に破壊的変更はない。
- **本リポジトリへの破壊的影響**: **なし**。`actions/cache` は 5 箇所（`.github/workflows/e2e.yml`・`e2e-nightly.yml`・`vscode-e2e.yml`（2 箇所）・`vscode-screenshots.yml`）で標準的な `key` / `path` 指定のみに使用しており、v6 でも API は不変。ESM 化は action 内部実装で利用側に不可視。read-only token 対応はむしろ bot / fork PR で有益。
- **pin 整合性**: 本リポジトリは全箇所で `actions/cache` を**フル commit SHA pin**（`# v5.0.5` コメント付き）。PR は SHA を `27d5ce7…`（v5.0.5）→ **`55cc8345863c7cc4c66a329aec7e433d2d1c52a9`（v6.1.0）** に更新する。upstream の tag `v6.1.0` を解決すると当該 commit に**完全一致**し（`gh api repos/actions/cache/git/refs/tags/v6.1.0` で確認）、SHA とタグの不整合はない。
- **メンテナ・所有権の変化**: リポジトリは GitHub 公式の `actions` org。リリース著者は v6.1.0 が `danwkennedy`、v6.0.0 が `Samirat`（いずれも actions 側コントリビュータ）。org・配布主体の移管や改名はなし。
- **lifecycle スクリプト**: GitHub Action のため postinstall / prepare 等は利用側で実行されない。
- **依存ツリーの変化**: action のバンドル内部の依存更新のみで、karasu の依存ツリー（`node_modules`）には影響しない。
- **公開からの経過時間**: v6.1.0 は 2026-06-26 公開（triage 時点で約 12 日）。本リポジトリの cooldown（全 semver レベル 7 日）を満たす。
- **既知 advisory**: 該当なし。

リスクレベル **low**。

## 決定

- **PR #1853 を squash merge する**（マージ済み）。`actions/cache` の major 更新だが CI 専用で、karasu に該当する破壊的挙動変更がない。
- `.github/dependabot.yml` は変更しない。

## 理由

- CI 専用の GitHub Action で、ランタイム成果物（core / app / cli / lsp / vscode）には影響しない。
- major 化の主因（ESM 化・内部依存 bump）は karasu に破壊的影響を与えない。利用側 API は不変。
- 全 required check が green。
- 全箇所で SHA pin を維持しており、upstream の tag `v6.1.0` が pin 先 SHA に完全一致。タグ改ざんによる差し替えリスクを受けない。
- 公開から約 12 日経過し cooldown を満たす。

## 却下した案

- **マージを見送り様子見する案**: 採用しなかった。フル SHA pin される GitHub Action の更新で、tag と pin 先 SHA が一致し、major 化の挙動変更が karasu の使用箇所に該当しない本件では、待機の積極的理由がない。

## スコープ外

- `actions/cache` の今後の更新（本 triage 時点では未起票）。
- 次回以降のバッチで複数 PR の競合や CI 失敗が発生する場合は、本 ADR と同様にバッチ ADR で triage する。
