分かったこと

  • A（PR #3882 のまま: ghost: true + ghostBand、ghost の祖先の枠と同じ描画）と B（Design Doc どおり: ghost: false + ghostBand、containerStyleOf を通さない専用の分岐で「ghost system の枠と同じ muted の枠」を描く）は、ダーク・ライトとも ピクセル単位で同じだった（差分 0）。Design Doc が指定した見た目がいまの描画と同じなので、分岐を分けただけでは見た目は変わらない。
  • 専用の分岐を持つと、帯の枠にだけ別の見た目を与えられる。C はその一例で、枠全体を薄くせず、破線と textMuted のタイトルをそのままの濃さで描き、枠の中にごく薄い地を敷いた。中の ghost のカードと線は今と同じ muted のまま。外部ドメインの名前が読めるようになる。
  • B / C の代わりに要るもの: ghost: false の帯の枠を「焦点の枠」と取り違えないよう、containers.find((c) => !c.ghost) の 5 か所（layout-edges 3・ghost-layout 1・ghost-band 1）を帯の枠を除く形にする必要がある（spike では帯の枠が焦点の枠より後ろに積まれるので今は当たらない）。draw.io の書き出しも帯の枠を ghost として扱う分岐が要る（spike で足した）。
